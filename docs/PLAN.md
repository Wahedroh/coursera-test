## 1. ภาพรวม

เว็บสำหรับนักเรียนเข้ามาดูคลิปเรียนย้อนหลัง แยก 2 คอร์ส คือ **คอร์ส ม.1&2** และ **คอร์ส ม.4**
นักเรียนสมัครแล้วต้องรอครูยืนยันก่อนดูคลิป ฝั่งครูมีหน้าหลังบ้านจัดการทุกอย่าง

## 4. ฝั่งนักเรียน

### 4.1 สมัคร / เข้าสู่ระบบ
- **แบบตั้งรหัสเอง**: ชื่อเข้าใช้ = **เบอร์นักเรียน** + รหัสผ่าน
- **แบบ Facebook**: เข้าครั้งแรกต้องกรอกฟอร์มโปรไฟล์ให้ครบก่อนส่งให้ครูยืนยัน (ไม่มี Google)
- ฟอร์มสมัคร:
  - ชื่อ, นามสกุล
  - โรงเรียน — พิมพ์เอง มีรายชื่อโรงเรียนที่เคยกรอกเด้งให้เลือก
  - เบอร์นักเรียน — ตัวเลข 10 หลัก ขึ้นต้นด้วย 0, **ห้ามซ้ำ**
  - เบอร์ผู้ปกครอง — ตัวเลข 10 หลัก ขึ้นต้นด้วย 0
  - คอร์ส — เลือกได้ **1 คอร์ส** (ม.1&2 หรือ ม.4); เปลี่ยนเองไม่ได้ ต้องให้ครูเปลี่ยน
  - ช่องติ๊ก **ยินยอมให้เก็บข้อมูล** (PDPA) พร้อมลิงก์นโยบายความเป็นส่วนตัว
- **เข้าได้ทีละ 1 เครื่อง**: เข้าเครื่องใหม่ เครื่องเก่าหลุดทันที
- **ลืมรหัสผ่าน**: แสดงข้อความให้ติดต่อครู (ครูตั้งรหัสใหม่ให้จากหลังบ้าน)

### 4.2 สถานะบัญชี
| สถานะ | นักเรียนเห็น |
|---|---|
| รอยืนยัน | หน้า "รอครูยืนยัน" + ประกาศ (ไม่เห็นคลิป) |
| ยืนยันแล้ว | คลิป + เอกสาร + ประกาศ ของคอร์สตัวเอง |
| ปฏิเสธ | ข้อความแจ้งว่าไม่ได้รับการยืนยัน ให้ติดต่อครู |
| ระงับ | ข้อความแจ้งว่าบัญชีถูกระงับ ให้ติดต่อครู |

### 4.3 หน้าเรียน
- หน้าแรก: ประกาศ (ทุกคน + เฉพาะคอร์สตัวเอง) และ "เรียนต่อจากล่าสุด"
- รายการ **บท → คลิป** เรียงตามที่ครูจัด แสดง % ที่ดูแล้วของแต่ละคลิป
- เปิดคลิป → **เล่นต่อจากจุดที่หยุดล่าสุด** (เก็บที่เซิร์ฟเวอร์ ข้ามเครื่องได้)
- ใต้คลิป: ปุ่ม **ดาวน์โหลดเอกสารประกอบ** และ **ดาวน์โหลดเอกสารที่เขียนแล้วในห้อง** (ถ้ามี)

### 4.4 ตัวเล่นคลิปแบบป้องกัน
กันได้ไม่ 100% (คนใช้ DevTools ยังหา ID คลิปได้) แต่ทำให้ยากและไม่คุ้มที่จะแชร์:
1. ครูตั้งคลิปบน YouTube เป็น **Unlisted**
2. ใช้ YouTube IFrame Player API ซ่อนปุ่มของ YouTube (`controls=0`, `disablekb=1`, `rel=0`, `fs=0`) แล้วทำ **ปุ่มควบคุมของเราเอง** (เล่น/หยุด, เลื่อน, ความเร็ว, เสียง, เต็มจอ)
3. **ชั้นบัง (overlay)** ทับทั้งกรอบคลิป กดโลโก้/ชื่อคลิปไม่ได้ ไม่มีทางออกไป YouTube
4. **ปิดคลิกขวา** ในกรอบคลิป
5. **ลายน้ำชื่อ + เบอร์นักเรียน** ลอยบนคลิป ย้ายตำแหน่งเป็นระยะ
6. เต็มจอใช้ fullscreen ของกรอบเราเอง (overlay + ลายน้ำยังอยู่)
7. ID คลิปส่งให้เฉพาะนักเรียนที่ยืนยันแล้วและอยู่คอร์สนั้นเท่านั้น

### 4.5 บันทึกความคืบหน้า
- บันทึกทุก **15 วินาที** ขณะเล่น + ตอนกดหยุด + ตอนปิด/ออกจากหน้า (`sendBeacon`)
- เก็บ **1 แถวต่อ นักเรียน × คลิป** แล้วเขียนทับ (ไม่เก็บประวัติทุกครั้ง)
- ค่าที่เก็บ: จุดหยุดล่าสุด, จุดไกลสุดที่ดูถึง, เวลาดูรวม, เวลาดูล่าสุด → คำนวณ % ที่ดู

## 5. ฝั่งครู (หลังบ้าน)

- เข้าด้วย **Facebook** เท่านั้น อนุญาตเฉพาะ Facebook user ID ใน `ADMIN_FACEBOOK_IDS` (ตอนนี้มีครู 1 คน, เพิ่มคนได้ภายหลัง)
  - Facebook ให้ ID เฉพาะแอป ครูจึงไม่รู้ ID ล่วงหน้า: เข้าครั้งแรกระบบจะแสดง ID ของบัญชีนั้น ให้นำไปใส่ใน `ADMIN_FACEBOOK_IDS`
  - session ครูอายุ 30 วัน; ลบ ID ออกจาก `ADMIN_FACEBOOK_IDS` = หมดสิทธิ์ทันที (ตรวจทุก request)

| เมนู | ทำอะไรได้ |
|---|---|
| นักเรียน | รายชื่อ + ค้นหา/กรองตามคอร์ส/สถานะ/โรงเรียน; **ยืนยัน / ปฏิเสธ / ระงับ**; เปลี่ยนคอร์ส; **ตั้งรหัสผ่านใหม่** |
| ประวัติการเรียน | ต่อนักเรียน ต่อคลิป: **% ที่ดู, หยุดล่าสุดนาทีไหน, ดูล่าสุดเมื่อไร, เวลาดูรวม** |
| บทและคลิป | เพิ่ม/แก้/ลบบท และคลิป (วางลิงก์ YouTube → ดึง ID อัตโนมัติ); **ลากเรียงลำดับ** |
| เอกสาร | อัปโหลด PDF (≤ 10MB/ไฟล์) ผูกกับคลิป 2 ประเภท: เอกสารประกอบ / เอกสารที่เขียนแล้วในห้อง |
| ประกาศ | สร้าง/แก้/ลบ ประกาศถึง **ทุกคน** หรือ **เฉพาะคอร์ส** |
| สำรองข้อมูล | ปุ่มดาวน์โหลด **CSV (เปิดใน Excel ได้, UTF-8 BOM)** รายชื่อ + ประวัติการเรียน; ปุ่มดาวน์โหลด **JSON** ทั้งฐานข้อมูล; ปุ่ม **กู้คืนจากไฟล์ JSON** (ไม่รวมไฟล์ PDF ใน R2) |
| พื้นที่ | แสดงการใช้ D1 / R2 เป็น % ของโควตาฟรี, เตือนเมื่อเกิน **80%** |
| ปิดปีการศึกษา | สำรองข้อมูลก่อน (บังคับดาวน์โหลด JSON) → เลือกปีการศึกษาที่สมัคร + คอร์ส (หรือทุกคอร์ส) → ลบนักเรียนกลุ่มนั้นและประวัติการเรียน; เลือกได้ว่าจะลบเอกสารของคอร์ส (ไม่ลบ / เฉพาะเอกสารที่เขียนในห้อง / ทั้งหมด) และลบประกาศทั้งหมดหรือไม่; แสดงจำนวนที่จะลบก่อนยืนยัน |

## 6. การอยู่ใน free tier ได้ตลอด

โควตาฟรีของ Cloudflare (ตรวจตัวเลขล่าสุดอีกครั้งก่อนเริ่มทำ):

| บริการ | โควตาฟรี (โดยประมาณ) |
|---|---|
| Workers | 100,000 requests/วัน |
| D1 | 500MB ต่อฐานข้อมูล, 5GB ต่อบัญชี, อ่าน 5 ล้านแถว/วัน, เขียน 100,000 แถว/วัน |
| R2 | เก็บ 10GB, Class A 1 ล้านครั้ง/เดือน, Class B 10 ล้านครั้ง/เดือน, ไม่คิดค่า egress |

มาตรการ:
- คลิปอยู่บน YouTube → ไม่กินพื้นที่
- ความคืบหน้า 1 แถว/นักเรียน/คลิป เขียนทับ; บันทึกทุก 15 วิ ≈ 240 ครั้ง/ชม./คน → รับได้ราว 400 ชั่วโมง-นักเรียน/วัน
- จำกัด PDF ≤ 10MB/ไฟล์
- หน้าแสดงการใช้พื้นที่ + เตือน 80%
- ปุ่มปิดปีการศึกษา ล้างข้อมูลรุ่นเก่าหลังสำรอง

## 7. โครงสร้างข้อมูล (D1)

```
students        id, first_name, last_name, school, student_phone (unique), parent_phone,
                course ('m12' | 'm4'), status ('pending'|'approved'|'rejected'|'suspended'),
                password_hash (null ถ้าใช้ Facebook), consent_at, academic_year,
                created_at, updated_at
oauth_accounts  id, student_id, provider ('facebook'), provider_user_id (unique ต่อ provider)
oauth_pending   id, provider, provider_user_id, display_name, expires_at   -- พักตัวตน Facebook ระหว่างกรอกโปรไฟล์ครั้งแรก (30 นาที)
sessions        id, student_id (unique → 1 เครื่อง/บัญชี), created_at, expires_at
admin_sessions  id, facebook_user_id, created_at, expires_at
schools         name (unique)                     -- สำหรับเด้งรายชื่อโรงเรียน
chapters        id, course, title, sort_order
videos          id, chapter_id, title, youtube_id, duration_sec, sort_order
documents       id, video_id, kind ('handout'|'class_notes'), r2_key, filename, size_bytes
progress        student_id, video_id, last_position_sec, max_position_sec,
                watch_seconds, last_watched_at      -- PK (student_id, video_id)
announcements   id, target ('all'|'m12'|'m4'), title, body, created_at
```

- รหัสผ่าน: อย่างน้อย 6 ตัว; เก็บแบบ PBKDF2-SHA256 **20,000 รอบ** + salt ต่อคน (100,000 รอบใช้ CPU ~17ms เกินลิมิต 10ms ของแผนฟรี; จำนวนรอบเก็บในค่าที่บันทึก เพิ่มภายหลังได้)
- Session: อายุ **30 วัน**, cookie `HttpOnly; Secure; SameSite=Lax`; เข้าเครื่องใหม่ = แทนที่ session เดิม (เครื่องเก่าหลุด)
- ปีการศึกษา: คำนวณอัตโนมัติตามเวลาไทย — พ.ค.–ธ.ค. = ปี พ.ศ. ปัจจุบัน, ม.ค.–เม.ย. = ปีก่อน

## 8. API (ร่าง)

```
POST /api/auth/register            สมัครแบบเบอร์ + รหัส
POST /api/auth/login               เข้าด้วยเบอร์ + รหัส
GET  /api/auth/facebook, /callback OAuth นักเรียน
POST /api/auth/complete-profile    กรอกโปรไฟล์หลัง OAuth ครั้งแรก
POST /api/auth/logout
GET  /api/me                       โปรไฟล์ + สถานะ
GET  /api/schools?q=               เด้งรายชื่อโรงเรียน
GET  /api/announcements
GET  /api/course                   บท + คลิป + % ที่ดู (ต้องยืนยันแล้ว)
GET  /api/videos/:id               youtube_id + จุดเล่นต่อ + รายการเอกสาร
POST /api/videos/:id/progress
GET  /api/documents/:id            ส่งไฟล์จาก R2 (ตรวจสิทธิ์ก่อน)

/api/admin/*                       (ต้องเป็น admin)
  auth/facebook, auth/callback
  students (list/filter), students/:id (status, course, reset-password)
  students/:id/progress
  chapters, videos (CRUD + reorder)
  documents (upload ≤10MB, delete)
  announcements (CRUD)
  backup/csv, backup/json, restore
  usage
  close-year
```

## 9. หน้าเว็บ

**นักเรียน**: เข้าสู่ระบบ, สมัคร, กรอกโปรไฟล์ (หลัง OAuth), รอยืนยัน/ปฏิเสธ/ระงับ, หน้าแรก (ประกาศ + เรียนต่อ), รายการบท-คลิป, หน้าดูคลิป + เอกสาร
**ครู**: เข้าสู่ระบบ (Facebook), นักเรียน, ประวัติการเรียนรายคน, บทและคลิป, ประกาศ, สำรอง/กู้คืน, พื้นที่, ปิดปีการศึกษา
**ทั่วไป**: นโยบายความเป็นส่วนตัว, ข้อตกลงการใช้งาน

## 10. สิ่งที่ครูต้องเตรียม (ทำเองนอกโค้ด)

1. บัญชี Cloudflare (ใช้แผนฟรี)
2. **Facebook Login** (ใช้ทั้งนักเรียนและครู): สร้างแอปใน Meta for Developers, ตั้ง redirect URL 2 อัน: `https://<โดเมน>/api/admin/auth/callback` (ครู) และ `https://<โดเมน>/api/auth/facebook/callback` (นักเรียน), ใส่ URL นโยบายความเป็นส่วนตัว (Meta บังคับให้มีวิธีขอลบข้อมูลด้วย — ระบุไว้ในหน้านโยบาย), เปลี่ยนแอปเป็นโหมด Live
3. ตั้งคลิปบน YouTube เป็น **Unlisted** และ **อนุญาตให้ฝัง (embed)**
4. ค่าลับใส่ผ่าน `wrangler secret` (ไม่เก็บใน repo): `FACEBOOK_APP_ID/SECRET`, `SESSION_SECRET`, `ADMIN_FACEBOOK_IDS`
