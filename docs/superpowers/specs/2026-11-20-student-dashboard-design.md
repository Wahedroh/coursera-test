# หน้าแรกแบบแอป + แถบเมนูล่าง + หน้าสรุปของครู

วันที่ 2026-11-20 · ภาพตัวอย่างที่ตกลงกันแล้ว: mockup รอบ 2 (หน้าแรก / คลิปทั้งหมด / คำถามของฉัน / บัญชี / สรุปของครู)

## ทำไม

ครูชอบหน้าตาแบบแอป (ตัวอย่างอ้างอิง: แอปแจ้งค่าบริการรายเดือนที่มีการ์ดใหญ่ "ถัดไป", การ์ดตัวเลข, แถบแจ้งเตือน, รายการจัดกลุ่ม, เมนูล่างจอ)
และอยากให้นักเรียนเปิดเว็บแล้วรู้ทันทีว่าต้องเรียนอะไรต่อ ครูเปิดหลังบ้านแล้วรู้ทันทีว่ามีงานอะไรรออยู่
นักเรียนส่วนใหญ่ใช้ iPhone และเพิ่มเว็บไว้บนหน้าโฮม จึงควรใช้งานรู้สึกเหมือนแอป

## เป้าหมาย

1. การ์ด "เรียนต่อ" ใบใหญ่
2. การ์ดตัวเลข 2 ใบ (ดูจบแล้ว, เวลาเรียน 7 วันล่าสุด)
3. แถบแจ้งเตือน (ครูตอบคำถามแล้ว, ดูค้างไว้)
4. รายการคลิปจัดกลุ่มตามบท พร้อมสถานะสีด้านขวา
5. แถบเมนูล่างจอ: หน้าแรก / คลิปทั้งหมด / คำถามของฉัน / บัญชี
6. หน้า "สรุป" ของครู เป็นเมนูแรกของหลังบ้าน

## ไม่ทำ (non-goals)

- ไม่เปลี่ยนธีม (กรม/เหลือง/ส้ม, ตัวอักษรสติกเกอร์ Kanit) และไม่เปลี่ยนหน้าดูคลิป ยกเว้นรองรับการเปิดตรงนาที
- ไม่เพิ่มส่วน "สำรองข้อมูลล่าสุด" หรือ "เข้าเรียนล่าสุด" ในหน้าสรุปของครู
- ไม่ทำแอปจริง / แจ้งเตือนแบบ push

## ข้อจำกัด

- Cloudflare แผนฟรี: Worker CPU 10ms ต่อคำขอ, D1 500MB → คิวรีต้องเบา, ตารางใหม่ต้องลบข้อมูลเก่าเอง
- นักเรียนที่ยังไม่ได้รับการยืนยัน / ถูกระงับ ไม่เห็นหน้าใหม่ (เห็นหน้าสถานะแบบเดิม)
- ฐานข้อมูลจริงต้อง migrate ก่อน merge ทุกครั้ง และต้องได้รับอนุญาตจากครู

## วิธีที่พิจารณา (เวลาเรียน 7 วัน)

| แบบ | วิธี | ข้อดี / ข้อเสีย |
|---|---|---|
| **A (เลือก)** | ตารางใหม่ `watch_daily(student_id, day, seconds)` บวกเวลาทุกครั้งที่บันทึกความคืบหน้า, ลบแถวเก่ากว่า 8 วัน | ตัวเลขตรงจริง พื้นที่น้อย · ตัวเลขเริ่มนับจากวันที่ขึ้นเว็บ |
| B | ประมาณจาก `progress.watch_seconds` ของคลิปที่ดูล่าสุดใน 7 วัน | ไม่ต้องแก้ฐานข้อมูล · ตัวเลขเกินจริง |
| C | ตัดการ์ดเวลาเรียน | ง่ายสุด · ไม่ตรงข้อ 2 ที่ตกลง |

ครูเลือก **แบบ A** เพราะตัวเลขตรงจริง

## สิ่งที่ครูตัดสินใจแล้ว

- หน้าแรกกับคลิปทั้งหมด **แยกกัน**: หน้าแรก = การ์ดเรียนต่อ + ตัวเลข + แจ้งเตือน + ประกาศ + คลิปใหม่; รายการบททั้งหมดอยู่แท็บ "คลิปทั้งหมด"
- เวลาเรียน = **7 วันล่าสุด** (ย้อนหลัง 7 วันตามวันเวลาไทย รวมวันนี้)
- หน้าสรุปของครู = **เมนูใหม่ "สรุป" เป็นหน้าแรก** ของหลังบ้าน
- "ดูค้างไว้ N คลิป" **นับรวม** คลิปในการ์ดเรียนต่อ, กดแล้วไปหน้าคลิปทั้งหมด (บทที่มีคลิปค้างกางอยู่)
- ประกาศบนหน้าแรก **แสดง 2 อันล่าสุด + ปุ่ม "ดูประกาศทั้งหมด"** (กางในที่เดิม)
- บทที่ดูจบครบ **ย่อเป็นแถวเดียว กดเพื่อกาง**
- ไม่มีคลิปใหม่ใน 7 วัน → **ซ่อนส่วน "คลิปใหม่"**
- ปรับตาม mockup รอบ 2 ทั้ง 12 จุด (ไอคอนเส้นแทนอีโมจิ, หน้า "บัญชี" ใหม่, ลิงก์ท้ายเว็บอยู่เหนือแถบเมนู, ลูกศรเฉพาะการ์ดที่กดได้, แถบความคืบหน้าสีเหลืองบนการ์ดใหญ่, สถานะ "ยังไม่ได้ดู" สีเทา + วงส้มสำหรับคลิปค้าง, ป้าย "ใหม่" ที่คำตอบที่ยังไม่เปิด + จุดตัวเลขบนแท็บคำถาม, เมนูหลังบ้านแถวเดียวเลื่อนได้บนมือถือ, ไม่มีไอคอนทับบนการ์ดครู, ตัวเลขรอยืนยันบนเมนู "นักเรียน", ตัดส่วนที่ไม่ได้ขอออก)

## การออกแบบ

### ฐานข้อมูล (migration `0006_dashboard.sql`)

- `watch_daily (student_id → students ON DELETE CASCADE, day TEXT 'YYYY-MM-DD' เวลาไทย, seconds INTEGER, PRIMARY KEY (student_id, day))`
- `questions.answer_seen_at INTEGER NULL` — เวลาที่นักเรียนเห็นคำตอบล่าสุด; คำตอบ "ใหม่" = `answered_at > COALESCE(answer_seen_at, 0)`
- ไฟล์สำรอง JSON: เวอร์ชัน 5 เพิ่ม `questions.answer_seen_at` (ค่าเริ่มต้นตอนกู้ไฟล์เก่า = `answered_at` ถือว่าเห็นแล้ว); `watch_daily` **ไม่สำรอง** (ข้อมูลชั่วคราว 8 วัน)

### API

- `POST /videos/:id/progress` (เดิม) — เพิ่ม upsert `watch_daily` ด้วยเวลา delta เดิม และลบแถวของนักเรียนคนนี้ที่เก่ากว่า 8 วัน ใน batch เดียวกัน
- `GET /home` (ใหม่, นักเรียนที่ยืนยันแล้ว) คืน:
  - `resume`: คลิปล่าสุดที่ดูค้าง หรือคลิปแรกของคอร์สถ้ายังไม่เคยดู (`started: false` → การ์ดขึ้น "เริ่มเรียน") พร้อม บทที่, ลำดับคลิปในบท/จำนวนคลิปในบท, ตำแหน่งค้าง, %
  - `stats`: `{ done, total, weekSeconds }`
  - `alerts`: `{ newAnswers, inProgress }` (คลิปที่ 0 < % < 100)
  - `newVideos`: คลิปใหม่ใน 7 วันที่ยังไม่ได้ดู (ใช้กฎ "ใหม่" เดิม)
- `GET /course` (เดิม) — ใช้ต่อในหน้าคลิปทั้งหมด (มี % และ isNew อยู่แล้ว)
- `GET /my-questions` (ใหม่) — คำถามทั้งหมดของฉัน + ชื่อคลิป + `isNew` ของคำตอบ; การเปิดหน้านี้ตั้ง `answer_seen_at = unixepoch()` ให้คำถามที่ตอบแล้ว (ใช้แคช 5 วินาทีกันโหลดซ้ำแบบเดียวกับประกาศ)
- `GET /admin/summary` (ใหม่) คืน: คำถามรอตอบ (จำนวน + ข้อล่าสุดพร้อมชื่อ/คลิป/นาที), นักเรียนยืนยันแล้วแยกคอร์ส, ไม่เข้าเรียนเกิน 7 วัน + ยังไม่เคยดู, นักเรียนรอยืนยัน, คลิปที่ยังไม่มีใครดูจบ
- ตัวเลขบนเมนูหลังบ้าน: ขยาย `/admin/questions/pending-count` เป็น `/admin/badges` คืน `{ questions, students }`

### หน้าจอนักเรียน

- โครงใหม่ `StudentShell` = หน้าเนื้อหา + ลิงก์ท้ายเว็บ + แถบเมนูล่าง (ไม่แสดงในหน้าดูคลิป)
- เส้นทาง: `/` หน้าแรก, `/clips` คลิปทั้งหมด, `/questions` คำถามของฉัน, `/account` บัญชี (ข้อมูล + "เปลี่ยนรหัสผ่าน" → `/account/password` + ออกจากระบบ), `/watch/:id?t=วินาที` เปิดตรงนาที
- จุดตัวเลขบนแท็บ "คำถามของฉัน" = จำนวนคำตอบใหม่
- หน้า "คลิปทั้งหมด": บทที่ดูจบครบย่อไว้, บทที่มีคลิปค้างกางเสมอ

### หน้าจอครู

- เมนู: สรุป (`/admin`, หน้าแรก) / นักเรียน (`/admin/students`) / ภาพรวม / คำถาม / บทและคลิป / ประกาศ / ข้อมูล
- การ์ดใหญ่: มีคำถามรอตอบ → แสดงข้อล่าสุด; ไม่มี → "นักเรียนรอยืนยัน N คน"; ไม่มีทั้งสองอย่าง → "ไม่มีงานค้าง 🎉"
- การ์ดตัวเลข → กดไป "นักเรียน" (ยืนยันแล้ว) และ "ภาพรวม" (ตัวกรองไม่เข้าเรียนเกิน 7 วัน)
- แถบแจ้งเตือน → "นักเรียนรอยืนยัน" ไปหน้านักเรียน (กรองรอยืนยัน), "คลิปที่ยังไม่มีใครดูจบ" ไปหน้าภาพรวม; ซ่อนแถวที่เป็น 0

## เรื่องที่ผู้สร้างตัดสินเอง (my calls)

- สีสถานะ: จบแล้ว = เขียว, ค้าง = ส้ม, ใหม่ = เหลืองเข้ม, ยังไม่ได้ดู = เทา
- ไอคอนแถบเมนูเป็น SVG เส้นในโค้ด (ไม่โหลดไลบรารีเพิ่ม)
- ลิงก์ "สำหรับครู" ยังอยู่ท้ายเว็บ
- เปิดคลิปที่มีคำตอบใหม่ (ช่องถามครูใต้คลิป) ก็นับว่าเห็นคำตอบแล้วเช่นกัน
- หน้าเปลี่ยนรหัสผ่านเดิมย้ายไป `/account/password` (เนื้อหาไม่เปลี่ยน)

## การทดสอบ

- e2e ด้วย Playwright บน iPhone 13: หน้าแรก (นักเรียนใหม่/มีคลิปค้าง/ไม่มีคลิปใหม่), เวลาเรียน 7 วัน (แถวเก่าถูกลบ, นับเฉพาะ 7 วัน), คำตอบใหม่ + จุดตัวเลข, คลิปทั้งหมด (ย่อ/กาง), บัญชี, เปิดคลิปตรงนาที, นักเรียนรอยืนยันไม่เห็นแถบเมนู
- หลังบ้าน: หน้าสรุป 3 สถานะของการ์ดใหญ่, ตัวเลขบนเมนู, ลิงก์ไปหน้าที่ถูก
- สำรอง/กู้คืนเวอร์ชัน 5 และกู้ไฟล์เวอร์ชัน 4
- ชุดทดสอบข้อ 10 (e2e12) ยังผ่าน
